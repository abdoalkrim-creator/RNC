# حاسبة المعالجة الصوتية للفراغات

## الرفع إلى GitHub Pages
1. أنشئ مستودعاً جديداً عاماً (Public) في GitHub.
2. ارفع جميع الملفات والمجلدات الموجودة في هذا المجلد إلى جذر المستودع، وتأكد من وجود index.html وmanifest.json وsw.js ومجلد icons.
3. من Settings ثم Pages، اختر Deploy from a branch ثم الفرع main والمجلد / (root) واضغط Save.
4. بعد دقائق يظهر الرابط بصيغة https://اسمك.github.io/اسم-المستودع/

## التثبيت على الآيفون
1. افتح الرابط في Safari وأنت متصل بالإنترنت.
2. اضغط زر المشاركة ثم "إضافة إلى الشاشة الرئيسية".
3. افتح التطبيق من أيقونته. بعد أول تشغيل يعمل بدون إنترنت.

## ملاحظات
- البيانات تُحفظ داخل الجهاز. استخدم "صدّر نسخة احتياطية" بين وقت وآخر لحفظ ملف JSON، و"استورد نسخة" لاستعادته.
- لتحديث التطبيق بعد تعديل الملفات، ارفع النسخة الجديدة وغيّر اسم الكاش CACHE في sw.js (مثلاً إلى acoustic-calc-v4) حتى يحصل الجهاز على الإصدار الجديد.
